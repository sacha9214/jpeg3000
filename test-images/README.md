# Test images

Lossless PNG photos used by `compare.py` and `test_jpeg3000.py`. They come from the
[scikit-image](https://scikit-image.org) data set and are free of copyright restrictions:

| File | Size | Credit | License |
|---|---|---|---|
| `astronaut.png` | 512x512 | Astronaut Eileen Collins, NASA Great Images database | Public domain |
| `chelsea.png` | 451x300 | Chelsea the cat, photo by Stefan van der Walt | CC0 |
| `coffee.png` | 600x400 | Coffee cup, photo by Rachel Michetti, courtesy of Pikolo Espresso Bar | CC0 |
| `camera.png` | 512x512 (grayscale) | Photo by Lav Varshney | CC0 |

None of them was ever saved as JPEG, so no codec gets an unfair head start from an old 8x8 block grid.
